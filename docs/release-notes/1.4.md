## 新功能

- 新增设置窗口：在菜单底部点「设置…」或按 ⌘, 打开，提示音、开机自启、自动更新、工作时段都在这里；成就墙放在「关于」里
- 可以单独关闭不喜欢的护眼动作（至少保留一个）
- 开会、全屏等推迟提醒时，菜单里可以直接点「现在休息」
- 首次安装时有一页简短的使用指南，之后可在设置里重看
- 设置里可以「复制诊断信息」，反馈问题时附上（复制前可预览，不含任何统计数据）

## 改进

- 菜单变得更紧凑，展开全部内容也不会再超出屏幕
- 番茄仔演示两遍动作后就停下，不再一直动；鼠标移到提醒面板上会再演示一次
- 支持 VoiceOver 朗读剩余时间、时长和开关状态；提醒面板获焦后按 Esc 可稍后提醒或提前结束休息
- 工作时段外更省电

## 升级

已安装 1.2 及以上版本的用户会在菜单里收到更新提示，点「更新」即可自动安装。
