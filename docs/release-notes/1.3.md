## 新功能

- **工作时段**：可以只在设定的时间段和工作日提醒，时段外自动暂停，进入时段后自动开始
- **全屏时不打扰**：看视频、演示等全屏使用时，到点先不提醒，退出全屏后再提醒
- **专注模式联动**：在「系统设置 → 专注模式」里添加 EyeBreak 过滤条件，专注期间暂停提醒
- **快捷指令**：「快捷指令」App 里新增开始专注、暂停计时、开始休息、跳过休息
- **本周统计与小成就**：点菜单里今天的番茄，查看最近 7 天的柱状图和 8 个小成就
- **菜单栏显示倒计时**：在「更多设置」里打开后，番茄仔旁边会显示剩余时间
- **深色模式**：界面跟随系统深浅
- **英文界面**：系统语言为英文时自动显示英文

## 改进

- 不常用的设置收进「更多设置」，菜单更简洁
- 菜单底部新增「反馈」和「许可」
- 修复了若干问题，例如过了零点后今日番茄不刷新

## 升级

已安装 1.2 及以上版本的用户会在菜单里收到更新提示，点「更新」即可自动安装。
