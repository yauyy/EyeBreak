# EyeBreak 迭代清单

EyeBreak 开源免费，在 GitHub Releases 下载即可使用。暂不做签名公证，也不上架 App Store。

## 第一步：可靠性

- [x] 1. 离开电脑自动暂停：超过 5 分钟没有键鼠操作就暂停计时，回来后开始新一轮
- [x] 2. 提醒面板出现在鼠标所在的屏幕（多显示器）
- [x] 3. 开机自启开关
- [x] 4. 记住状态：退出或重启后恢复上次的计时
- [x] 5. 确认菜单栏番茄仔为彩色显示（已在真机上确认）

## 第二步：让提醒更好接受

- [x] 6. 稍后提醒：提醒面板加「5 分钟后」按钮
- [x] 7. 会议时不打扰：麦克风被会议软件占用时推迟提醒，结束后再弹（摄像头需要额外权限，不检测；需要开会时人工确认）
- [x] 8. 尊重「减少动态效果」：关闭撒花、浮动等动画

## 第三步：用番茄仔养成习惯

- [x] 9. 收集番茄：每完成一次休息收一个 🍅，显示今日数量和连续天数
- [x] 10. 休息内容轮换：看远处、眨眨眼、闭眼放松、转转眼球，番茄仔做对应动作
- [x] 11. 提示音设置：可关闭，或换一种音效

## 第四步：视觉细节

- [x] 12. 圆角规范：数值对齐 macOS 原生界面（按钮 8、卡片 12、面板 20），控件贴着边角时保持同心

## 第五步：更新

- [x] 13. 检查更新：读取 GitHub 最新 Release 版本，有新版本时在菜单里提示并跳转下载（可关闭自动检查）
- [x] 14. 应用内自动更新：接入 Sparkle，下载、校验签名、安装、重启一步完成（从 1.2 起）

## 第六步：开源基本功

- [x] 15. 加 LICENSE（MIT）
- [x] 16. 附上第三方许可声明（Sparkle），随 App 一起分发
- [x] 17. 「反馈问题」入口：打开 GitHub Issues，自动填好版本和系统信息

## 第七步：小而高频的功能

- [x] 18. 菜单栏显示剩余时间（可选，默认关闭）
- [x] 19. 工作时段：只在设定的时间段和工作日提醒
- [-] 20. ~~全局快捷键~~（暂不做）
- [x] 21. 全屏时不打扰：看视频、演示时推迟提醒

## 第八步：让番茄仔更有存在感

- [x] 22. 本周统计：7 天番茄柱状图
- [x] 23. 小成就：连续天数、单日数量等里程碑
- [x] 24. 快捷指令与专注模式联动

## 第九步：扩大受众

- [x] 25. 英文界面与英文 README
- [x] 26. 深色主题：跟随系统深浅

## 第十步：动效

- [x] 27. 番茄仔护眼动作动效：四个动作各有对应的眼睛动画，需要手势的加上哆啦A梦式小圆手（Canvas 设计稿见 Design/motion/）；提醒面板也会演示即将要做的动作

## 第十一步：1.3.2 修复

- [x] 28. 稍后提醒状态恢复：快照保存本轮稍后提醒标记与总时长，兼容旧快照，专注和暂停中重启都正确恢复
- [x] 29. 本次休息时长固定：休息中调整时长从下一轮生效，等待休息时调整立即生效，并补中英文提示
- [x] 30. 工作时段外主动开始：开始、继续等用户操作统一覆盖时段限制，自动行为保持工作时段约束
- [x] 31. 白字对比度：为按钮、选中项和徽章增加专用深浅色填充，白字对比度达到 4.5:1
- [x] 32. 打包构建号校验：读取线上 appcast 中的最大构建号，新构建号必须严格递增；读取或解析失败停止打包，本机测试可显式跳过并显示警告
