# EyeBreak 迭代清单

EyeBreak 开源免费，在 GitHub Releases 下载即可使用。签名公证、自动更新等分发相关工作暂不考虑。

## 第一步：可靠性

- [x] 1. 离开电脑自动暂停：超过 5 分钟没有键鼠操作就暂停计时，回来后开始新一轮
- [x] 2. 提醒面板出现在鼠标所在的屏幕（多显示器）
- [x] 3. 开机自启开关
- [x] 4. 记住状态：退出或重启后恢复上次的计时
- [ ] 5. 确认菜单栏番茄仔为彩色显示（需要在真机上人工确认）

## 第二步：让提醒更好接受

- [x] 6. 稍后提醒：提醒面板加「5 分钟后」按钮
- [ ] 7. 会议时不打扰：摄像头或麦克风使用中时推迟提醒，结束后再弹
- [ ] 8. 尊重「减少动态效果」：关闭撒花、浮动等动画

## 第三步：用番茄仔养成习惯

- [ ] 9. 收集番茄：每完成一次休息收一个 🍅，显示今日数量和连续天数
- [ ] 10. 休息内容轮换：看远处、眨眨眼、闭眼放松、转转眼球，番茄仔做对应动作
- [ ] 11. 提示音设置：可关闭，或换一种音效
