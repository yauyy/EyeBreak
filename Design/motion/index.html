设计与实现约定

模块划分：本页和 tomato-motion.js 提供六个动作的离线设计预览；「走一走」第 5 轮保持手部基准、肩根、脚与身体运动不变，只收小前摆并微调后摆下沉。允许手掌压到腮红，离线间距门槛改为双眼及嘴 ≥2、手脚 ≥2，保留脚部可见面积检查。沿用现有 100×100 坐标、配色与绘制函数，供后续移植 TomatoCharacter.swift 对照。喝水的下垂肘弯、侧握、倾杯、水平水面和放下姿势继续保留。

接口与交互：frame(motion, t) 以纯时间公式计算姿态，draw(ctx, motion, t) 绘制。动作演示和 76px 预览遵循系统的减少动态效果设置，静止代表帧一排始终显示代表时刻。?still 参数固定动作演示和 76px 预览的时间，静止代表帧一排不受影响；显式固定帧优先于系统设置，便于逐帧验收。

后台数据库：本次是纯绘制改动，不涉及数据存储或接口。

关联影响：本轮改动仅位于 Design/motion/tomato-motion.js 和 index.html；App 的 RestExercise、BreakPanel、TomatoCharacter.swift 留待画风验收通过后移植。

喝口水节奏：p = t mod 4，g 在 0～1s 用 ease(p) 抬杯，1～2.6s 保持 1，2.6～3.6s 用 1 − ease(p − 2.6) 放下，3.6～4s 保持 0；ease 沿用余弦缓动。持杯阶段 s = sin²(2π(p − 1) / 1.6)，其余为 0，在 1.4s、2.2s 各轻啜一次，起止速度为 0。代表帧登记为 1.4s；4s 整数倍为完整握杯的停顿姿势。

走一走节奏：一轮 3.6s，令 p = t mod 3.6，a = sin(2πp / 1.8)，e = ease(min(p, 3.6 − p) / 0.225)，w = ae；ease 沿用输入限制在 0～1 的余弦缓动。左脚抬起进度 L = max(0, a)²e，右脚 R = max(0, −a)²e；左右各迈两步，左脚峰值为 0.45 / 2.25s，右脚峰值为 1.35 / 3.15s。起止用 e 平滑收回摆动，0 / 3.6s 为双脚着地、双手回到腰部基准的同一站立姿势，有限播放两轮停在 7.2s 也保持完整；代表帧为 0.45s。

走一走重心与落脚：身体向着地侧平移 1.5w，上浮 2(L + R)，绕脚边支点 (50, 93) 倾斜 4.5w°；抬左脚时向右移、向右倾，抬右脚时镜像，迈步中段最高。落脚压扁只发生在 0.9 / 1.8 / 2.7s 的中途换步：取最近的落脚时刻 c = round(p / 0.9) × 0.9，仅当 0 < c < 3.6 时 q = 1 − ease(|p − c| / 0.16)，其余 q=0。沿用闭眼呼吸的支点缩放写法，纵向 scaleY = 1 − 0.02q，横向不缩放；落脚前后各 0.16s 平滑进入和恢复，最低时压扁 2%，0 / 3.6 / 7.2s 均恢复原站姿。眼睛睁开，保留原有小嘴与腮红。

走一走离线检查：在仓库根目录运行 node Design/motion/tomato-motion.js --check-walk，无需浏览器、网络或第三方依赖，不生成文件。遍历 0～3.6s，步长 0.0001s，共 36,001 个时刻，每个时刻检查左右手与左右脚的四种组合。使用与绘制共享的轮廓尺寸和脚姿态，将手掌椭圆及 2.2 描边经过身体平移、旋转、压扁和手部旋转后，与不随身体变换的脚椭圆及描边做凸形状投影分离检查，包含被身体盖住的轮廓。方向搜索取得的分离量为真实欧氏间距的保守下界；再按相对轮廓速度上界 400 单位/s，扣除半个采样间隔的 0.02 单位误差，验证整个连续周期。当前前后摆幅均受原较大摆幅的速度界覆盖；手掌含描边距身体支点全周期小于 44.1，满足推导所用半径 50。连续下界至少 2 才通过，否则命令返回非零退出码。修改公式时须同步核对代码内的速度界推导。命令同时输出 clearance（手脚）、faceClearance（手与双眼/嘴）及 visibility（脚部可见面积），三项全部通过才返回 0。
